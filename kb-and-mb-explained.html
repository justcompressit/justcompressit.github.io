KB vs MB: File Sizes Explained Simply

Forms ask for “under 100 KB” or “max 2 MB” – but how big is that, and how do you know what size your file is? Here's everything in one place.

The units

UnitEqualsRoughly
1 KB (kilobyte)1,024 bytesA short text document
1 MB (megabyte)1,024 KBA good-quality photo
1 GB (gigabyte)1,024 MBAbout an hour of HD video

Some systems use 1,000 instead of 1,024, so the same file may show slightly different sizes in different places. When a form has a strict limit, leave a small margin – aim for 95 KB if the limit is 100 KB.

Typical file sizes

  • Phone photo: 2–6 MB
  • Compressed photo for a form: 20–200 KB
  • Scanned document page: 100 KB–2 MB
  • Typed PDF page: 20–100 KB
  • One minute of phone video: 50–150 MB

How to check a file's size

  • Windows: right-click the file → Properties.
  • Mac: select the file → press Command + I.
  • Android: open the file in your Files app → tap the ⋮ menu → Details/Info.
  • iPhone: in the Files app, press and hold the file → Get Info.

Frequently asked questions

How many KB is 1 MB?

1,024 KB (some systems round to 1,000).

Is 500 KB bigger than 1 MB?

No. 500 KB is about half of 1 MB.
